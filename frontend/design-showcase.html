Module 3 · Structs & Register Mapping

Memory-Mapped Hardware Registers

In embedded systems, peripheral registers are accessed through fixed memory addresses. A volatile struct mapping lets the compiler know the values can change outside the program's flow.

register_map.c 
#define RCC_BASE     0x40021000
typedef struct {
  volatile uint32_t CR;    // control
  volatile uint32_t CFGR;  // clock config
  volatile uint32_t CIR;   // interrupt
} RCC_TypeDef;

#define RCC  ((RCC_TypeDef*)RCC_BASE)
RCC->CR  |= (1U << 16);  // HSE on
